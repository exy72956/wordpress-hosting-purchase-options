## 三、30 GB 空间和 3 TB 流量够不够跑 WordPress

WordPress 核心程序加主题插件占不了多少，几 GB 的量级，剩下全是图片和备份。30 GB 对文字为主的博客绰绰有余，图库型站点就紧张。腾讯云那篇部署文章给过一个参照：40GB 盘装完 WP 核心、主题和插件后还有空间放媒体文件。30 GB 比它少 10 GB，图片多的话要么压缩上传，要么直接上 85 GB 那档。

流量按单页 100 KB 粗算，3 TB 对应的月页面访问量在千万级，个人博客和大多数小企业站碰不到这个天花板。真正影响体验的是共享主机的资源争抢：同一台服务器上的邻居跑高负载程序，你的响应就会变慢，这是共享主机绕不过去的特性。想要独占 CPU 和内存，只能往 VPS 或云服务器走。

## 五、下单前后容易踩的坑

1. **别买错产品线。** 促销线和标准线同样 30 GB，价格差六倍，商品编号不同，结账前确认买的是年付促销那一条。
2. **算清域名额度。** 促销 30 GB 只给 3 个域名，85 GB 给 11 个，要挂更多站先数一遍。
3. **机房别用默认值。** 国内访客选洛杉矶，不同机房到国内的线路差别明显。
4. **腾讯云的秒杀有门槛。** 38 元只给个人新用户首单，每天 10:00 和 15:00 两场，错过就是 109 元。创建实例必须选 WordPress 应用镜像，选纯系统镜像就没有预装环境。
5. **DNS 生效后记得改站点地址。** 绑域名加 A 记录，生效后进 WordPress 后台把「WordPress 地址」和「站点地址」改成域名，否则页面资源继续指向 IP。
6. **SSL 在云服务器上不是自动的。** 轻量服务器要自己申请证书或装插件；RackNerd 那边是 Let's Encrypt 自动续期。

要跑 WooCommerce 且订单量不小，共享主机的资源上限会卡住你。手上有十几个客户站要分开管理，Reseller 线更合适。完全不想看技术界面、希望有人接电话处理故障，GoDaddy 那类托管型省心，代价是首年之后的报价要自己问清楚。访客主要在国内、对延迟敏感、还要走备案流程，腾讯云国内地域的轻量服务器更对路。

## 七、常见问题

### 1 核 1G 能跑 WordPress 吗？

共享主机不按核数和内存卖，按存储、流量、域名数卖，CPU 和内存是整台机器共享，所以「1 核 1G」只适用于 VPS 和云服务器。腾讯云那台 4核4G3M 是打包计价，4GB 内存跑 Nginx、MySQL、PHP-FPM 三个进程够用，上多语言、ACF 这类重插件也不至于卡。

### 能不能一键装 WordPress？

RackNerd 走 cPanel 里的 Softaculous，选中 WordPress、填站点名和管理员账号，几分钟装完。腾讯云走应用镜像，付款后 1–3 分钟实例带好环境，进安装向导填信息即可。

### 续费会涨吗？

三家在下单前都能查到：RackNerd 看结算页的循环金额，腾讯云看活动页的续费说明，GoDaddy 看首年方案到期后的报价。页面没写的价格，不要按首年价去假设。

### 不满意能退吗？

GoDaddy 提供 7 天免费试用。RackNerd 的退款条款在第三方页面上说法互相矛盾，一处说年付可按比例退，一处说付款后不退款，稳妥的做法是先买 $5.59 的月付标准版试一个月，或者下单前在结算页把条款读完。

### 国内用需要备案吗？

腾讯云的广州、上海、北京属于国内地域，域名对外提供访问要走备案流程。RackNerd 是海外主机，没有这一环，代价是国内访问速度取决于机房线路。
